# Установка и запуск MiHome-Windows (русская версия)

Требования: **Windows 11 x64** (Windows 10 x64 тоже должна работать), аккаунт Xiaomi
и приложение Mi Home на телефоне (для входа по QR-коду).

> **Важно.** Готовый `.exe` в этом архиве исходников не лежит: его нужно собрать
> (способ 1 или 2 ниже). Собирается он только в Windows.

---

## Способ 1. Готовая сборка из GitHub Actions (проще всего)

Сборка выполняется автоматически на серверах GitHub, ничего ставить не нужно.

1. Создайте на GitHub репозиторий и загрузите в него содержимое архива
   (папка `.github/workflows/` должна попасть в репозиторий).
2. Откройте вкладку **Actions → «build-windows» → Run workflow**
   (либо отправьте тег вида `v1.0.0-ru` — тогда архив появится ещё и в Releases).
3. Дождитесь зелёной отметки (обычно 15–40 минут: Nuitka компилирует проект).
4. Скачайте артефакт **`MiHome-Windows-ru-win64.zip`**.
5. Распакуйте архив в удобную папку, например `C:\Apps\MiHome-Windows`
   (путь без ограничений на кириллицу, но лучше обычный).
6. Запустите **`MiHome-Windows.exe`**.

Внутри собранной папки лежит `app\i18n\locales\ru.json` — это файл перевода,
его можно редактировать.

### Предупреждение SmartScreen / антивируса

Файл не подписан цифровой подписью, поэтому Windows может показать
«Windows защитила ваш компьютер». Нажмите **Подробнее → Выполнить в любом случае**.
Программы, скомпилированные Nuitka, иногда вызывают ложные срабатывания антивируса —
при необходимости добавьте папку программы в исключения. Если вы не доверяете
готовому `.exe`, соберите его сами (способ 2) из исходников.

## Способ 2. Сборка на своём компьютере

Нужно:

| Что | Версия |
|---|---|
| Python | 3.10 – 3.12, x64 |
| Visual Studio Build Tools | с компонентом «Разработка классических приложений на C++» (MSVC) |
| Windows SDK | 10/11 |
| Путь к проекту | **только латиница**, например `E:\Projects\MiHome-Windows` |

Путь с кириллицей или иероглифами ломает Nuitka (`depends.exe` не понимает не-ASCII), поэтому
`build.ps1` проверит это и остановится с подсказкой.

Шаги в PowerShell:

```powershell
cd E:\Projects\MiHome-Windows
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e .
pip install nuitka
python -m tests.i18n_test      # быстрая проверка перевода
.\build.ps1
```

Если PowerShell запрещает запуск скриптов:
`Set-ExecutionPolicy -Scope Process Bypass`.

Результат: `dist\MiHome-Windows.exe` и рядом папка `dist\app\i18n\locales\ru.json`.
Копируйте и запускайте **всю папку `dist`**, а не один `.exe`.

## Способ 3. Запуск из исходников (без сборки .exe)

1. Установите Python 3.10+ x64 с [python.org](https://www.python.org/downloads/)
   (отметьте «Add python.exe to PATH»).
2. Распакуйте архив исходников.
3. Дважды щёлкните **`start.bat`** — при первом запуске он создаст `.venv`, поставит
   зависимости и запустит программу.

Или вручную:

```powershell
cd путь\к\MiHome-Windows
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e .
python -X utf8 run.py
```

В этом режиме настройки хранятся в папке проекта. Чтобы использовать общую папку
данных, как у собранной версии, перед запуском задайте
`set MIHOME_DATA_DIR=%LOCALAPPDATA%\MiHome-Windows`.

## Первый запуск и вход

1. При первом запуске появится окно с **QR-кодом**.
2. На телефоне откройте приложение **Mi Home** и отсканируйте код (раздел сканирования
   в профиле/на главной).
3. Подтвердите вход на телефоне. После этого список устройств загрузится автоматически.

Данные для входа сохраняются в `C:\Users\<имя>\.config\mijia-api\auth.json`
(общие с консольным клиентом mijiaAPI). Чтобы выйти из аккаунта или войти заново,
переименуйте этот файл (например, в `auth.json.bak`) и запустите программу.

## Смена языка

**Настройки → Оформление → «Язык интерфейса / 界面语言»** → Русский / 中文 →
сохранить → согласиться на перезапуск. Подробности — в `README.ru.md`.

## Где хранятся данные

| Что | Где |
|---|---|
| Настройки, кэш устройств, расписания, виджет (сборка) | `%LOCALAPPDATA%\MiHome-Windows\` |
| Вход (токены) | `C:\Users\<имя>\.config\mijia-api\auth.json` |
| Журнал `debug.log` | рядом с данными (источник — корень проекта) |

## Автозапуск

Опция «Запуск при входе в Windows» в настройках (вкладка «Функции») пишет запись в реестр `HKCU\...\Run` и
работает **только в собранной версии** (`.exe`), не при запуске из исходников.

## Удаление

1. Закройте программу (в том числе из значка в трее → «Выход»).
2. Отключите «Запуск при входе в Windows» в настройках (до удаления).
3. Удалите папку с программой.
4. При желании удалите `%LOCALAPPDATA%\MiHome-Windows` и
   `C:\Users\<имя>\.config\mijia-api\auth.json`.

## Если что-то не работает

| Проблема | Что делать |
|---|---|
| Не запускается / мгновенно закрывается | Запустите `start.bat` (из исходников) и посмотрите текст ошибки; журнал — `debug.log`. |
| SmartScreen блокирует `.exe` | «Подробнее → Выполнить в любом случае», см. выше. |
| Антивирус удалил файл | Добавьте папку в исключения или соберите сами. |
| Текст в каком-то окне обрезан | Сообщите, где именно; перевод можно сократить в `ru.json`. |
| Часть названий осталась на китайском | Это данные облака Xiaomi (устройства, комнаты, сценарии) — переименуйте локально в карточке устройства. |
| Вход не удаётся / устройства не грузятся | Переименуйте `auth.json` и войдите заново по QR-коду. |
| Сборка падает на этапе зависимостей | Проверьте, что путь к проекту — латиница, а MSVC и Windows SDK установлены. |
